🏢 بوت شركة ابو حريره - نظام احترافي زي زين
طريقة التشغيل خطوة بخطوة (Render.com مجاني)
الخطوة 1: التسجيل في موقع الاستضافة
افتح https://render.com
دوس Sign Up وسجل بايميلك (ممكن بجوجل مباشرة)
بعد التسجيل دوس Dashboard
الخطوة 2: رفع الملفات
في Render دوس New + > Web Service
اختار Connect a repository - أو ارفع مباشرة:
الحل السهل: افتح https://github.com/new وانشئ حساب github وسجل
ارفع ملفات bot.js و package.json و products.json هناك
ارجع ل Render واربط حساب Github واختار المشروع
الطريقة الاسهل بدون Github (Glitch.com):
افتح https://glitch.com
دوس New Project > glitch-hello-node
احذف كل الملفات وارفع ملفاتنا:
bot.js
package.json
products.json
افتح Terminal واكتب: npm install
بعدها: npm start
حيظهر رابط فوق - افتحه
الخطوة 3: مسح الباركود
افتح الرابط اللي عطاك ليه الموقع (مثلا https://abu-harera-bot.onrender.com)
حيظهر لك QR Code
افتح واتساب الشركة رقم 00249120240401
دوس: الإعدادات > الأجهزة المرتبطة > ربط جهاز
صور الباركود
الخطوة 4: التجربة
من رقم تاني ارسل "سلام" لرقم الشركة وشوف البوت يرد!

مميزات النظام الجديد:
✅ قائمة رئيسية مثل شركات الاتصالات
✅ اختيار بالارقام 1-5
✅ عرض ملخص قبل الصور
✅ ذكاء يفرق بين 2 دستة و 4 دستة
✅ يقرا من Google Sheet كل دقيقة
✅ ردود احترافية بايموجي
